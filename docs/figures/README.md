# Figures

`readme/` holds the screenshots the README shows, taken from running worlds on 2026-11-10 and 11:
`hero.png` (one window on one world: chat with typeset math and a TikZ diagram, the graph under the
twilight sky, a terminal held by the world, the log), `chat.png` (root swapping its own kernel: the
card, the approval, the restart, the report), `graph.png` (people, agents and Models with their
lines), `history.png` (the log view), `about.png` (a world saying what it runs).

The design drawings behind the ontology and the architecture live with the specification, which is
not in this tree; `docs/ontology.md` is generated from the schemas and is the current word.
