# Contributing

Pull requests are open. ORBIS is one person's project with a point of view, so read the point of view
first: `docs/ethos.md` for why, `docs/ground-rules.md` for what no change may break, `AGENTS.md` for how
a change gets in. Small, whole changes land; sweeping ones start as a conversation in an issue.

Add `Signed-off-by: Your Name <you@example.com>` to each commit (`git commit -s`) to say so. A pull
request whose commits lack it will be asked for it before review.

## What a change needs

- Tests with it. World behaviour is tested through the protocol as a named Principal; pure listener
  logic lives in `model/` or `chat/` with a Catch2 case; a UI control that issues a world op is driven
  end to end through the drive API. `make smoke` before you push, `make test` before you call it done.
- A row in `docs/decisions.md` if the contract moved, and `docs/protocol.md` updated with it, in the
  same commit. Schema changes are exported with `make schema-json` and the generated files committed.
- Comments that say why, for a reader who was not there. No session history, no attribution lines,
  no "generated by" trailers.
- One case for labels, one size inside a transcript, nothing drawn over code: `docs/listener-style.md`.

## What does not land

- Anything that lets an agent lift a gate, approve its own work, or change what a person decides.
  `docs/authority.md` is the boundary, and changes to it are the author's.
- A dependency added for a convenience the standard library gives.
- A change to the log format without a migration and a decisions row.

No support is promised. Issues are read; answers come when they come.
