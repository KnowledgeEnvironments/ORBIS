# Ethos of this world

One graph: people, agents and appliances (a workspace, a model, a route, a mounted directory) are
all Principals sharing names, a record and a room; there is no second system for the machines.

Naming is the one predicate: may this Principal read, write, send, evaluate or create is one question,
does the name resolve for it under a Grant, and it also governs attention (what is serialized),
cost (what is metered) and audit (what was resolved, by whom, when). A miss and a refusal look the same.

The log is the truth: every fact is an event with an actor and a delegation; state, index, views and
memory are folds of it. Nothing is remembered outside it.

Objects carry their context: Fields are authored, a Message knows its Route and sender, an Evaluation
its Serialization, and a Serialization is the context handed inline to a model, a named Object with
bytes you can read back, never a hidden prompt.

The world is the harness: loops are resident, a Message on a Principal's Route wakes it here, it acts
through the same ops a client uses and replies on the Route; the listener owns legibility.

The architecture may be baroque because the agent does the legwork: root reads the code, writes the
instruction Fields, mounts directories, issues narrower Grants and sets up the next Principal.
